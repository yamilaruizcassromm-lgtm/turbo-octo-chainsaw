Introducción

En este trabajo práctico reuní lo más importante que capté al ver el video sobre desarrollo web. La idea fue entender cómo se conectan las tecnologías que usamos a diario en informática para armar una página desde cero, aplicando buenas prácticas y viendo cómo todo cobra sentido cuando combinamos diseño, lógica y bases de datos.

Conceptos Fundamentales

Estructura Web (HTML5)

Es la base o el esqueleto de la página. Sirve para organizar los textos, imágenes y secciones con significado.

Estilos y Diseño (CSS3)

Es lo que le da color, forma y vida al sitio. Permite acomodar los elementos y hacer que se vea bien en celulares y computadoras.

Interactividad (JavaScript)

El motor dinámico. Permite que la página responda a las acciones del usuario, como clics, animaciones o validaciones.

Bases de Datos (SQL)

Donde se guarda la información de manera ordenada para poder consultar, actualizar o borrar datos cuando haga falta.

Publicación y Hosting

El paso final para subir nuestro proyecto a la nube y lograr que cualquier persona en internet pueda entrar a verlo.

Cuestionario Resuelto

Hacé clic en las preguntas para desplegar mis respuestas:

El video muestra paso a paso cómo se construye una aplicación web moderna. Se centra en explicar cómo trabajan juntas las tecnologías del lado del cliente y del servidor para crear un sitio que sea funcional, rápido y fácil de usar.

Aborda la necesidad de saber estructurar bien un proyecto web. Muchas veces los sitios son lentos o desordenados; el video enseña cómo organizar el código para que las páginas carguen rápido, se vean bien en cualquier pantalla y manejen datos sin errores.

1. HTML5: El esqueleto de la web para definir contenidos.
2. CSS3: El diseño visual, colores y distribución.
3. JavaScript: Otorga dinamismo e interactividad en tiempo real.
4. SQL: Lenguaje para comunicarnos con las bases de datos.
5. Responsive Design: La técnica para que todo se adapte al tamaño del celular o monitor.

Se utiliza VS Code para escribir el código, navegadores web para probar cómo va quedando, sistemas como MySQL para guardar información en tablas y servicios como GitHub o Netlify para publicar el sitio en internet.

  1. Maquetar la estructura inicial usando etiquetas HTML.
  2. Darle estilos, colores y fuentes con CSS.
  3. Agregar la lógica e interactividad con JS.
  4. Realizar pruebas locales para corregir posibles fallas.
  5. Desplegar la página en un servidor para que sea accesible públicamente.

Un buen ejemplo que mostraron fue la creación de un formulario de registro. Primero arman los campos en HTML, luego usan JS para verificar que el usuario no deje recuadros vacíos y, por último, envían esa información a una base de datos SQL.

No hace falta ser un experto, pero ayuda bastante tener una base de lógica de programación, saber manejar archivos en la computadora y entender cómo funciona internet a nivel general.

El principal beneficio es conseguir que el sitio sea rápido, seguro y accesible. Además, al escribir código limpio y ordenado, si el día de mañana querés cambiar algo, es mucho más fácil de modificar.

Hay que tener cuidado con no dejar brechas de seguridad al conectar la base de datos (para evitar inyecciones SQL), revisar que el diseño no se rompa en celulares y comprobar que no queden rutas o enlaces rotos.

Lo aplicaría diseñando una página funcional para un negocio local o incluso creando un sistema para el colegio, donde se puedan consultar avisos, horarios o descargar archivos de forma sencilla.

Para mí, la parte clave fue la integración entre JavaScript y la base de datos. Ahí es donde te das cuenta de cómo una página pasa de ser algo puramente visual a convertirse en una aplicación útil e interactiva.

Me sirvió para entender el panorama completo del desarrollo web. Me di cuenta de que no se trata solo de copiar código, sino de planificar bien la estructura para que la experiencia de quien usa la página sea la mejor posible.
